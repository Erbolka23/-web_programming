# Встречи

Веб-приложение для публикации и поиска мероприятий. Организаторы могут создавать события с описанием, местом, датой и постером, а посетители — искать события по названию и локации.

## Возможности

- Каталог событий с поиском и пагинацией по 6 записей.
- Страница события с датой, местом, описанием, организатором и постером.
- Регистрация, вход и выход пользователей.
- Создание событий авторизованными пользователями.
- Редактирование и удаление доступны только автору события.
- Загрузка постеров в `media/posters/`.
- Интерфейс на Bootstrap 5, адаптированный для мобильных экранов.

## Стек

- Python 3.12+
- Django 6.1
- SQLite
- Pillow для обработки изображений
- python-decouple для конфигурации через `.env`
- Bootstrap 5.3

## Установка

1. Клонируйте репозиторий и перейдите в его каталог:

	```powershell
	git clone <URL-репозитория>
	cd web_programming
	```

2. Создайте и активируйте виртуальное окружение.

	Windows PowerShell:

	```powershell
	python -m venv venv
	.\venv\Scripts\Activate.ps1
	```

	macOS или Linux:

	```bash
	python3 -m venv venv
	source venv/bin/activate
	```

3. Установите зависимости:

	```bash
	python -m pip install -r requirements.txt
	```

4. Создайте `.env` из шаблона `.env.example` и задайте собственный `SECRET_KEY`. Для генерации ключа выполните:

	```bash
	python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
	```

	Вставьте полученное значение в `SECRET_KEY` в `.env`. Для локального запуска установите `DEBUG=True`. Файл `.env` исключён из Git.

5. Примените миграции:

	```bash
	python manage.py migrate
	```

6. При необходимости создайте администратора:

	```bash
	python manage.py createsuperuser
	```

7. Запустите сервер разработки:

	```bash
	python manage.py runserver
	```

	Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Панель администратора доступна по адресу `/admin/`.

## Структура проекта

```text
config/                 настройки и корневые URL
events/                 модели, формы, представления и миграции
templates/              базовый шаблон, страницы событий и авторизации
media/posters/          загруженные постеры (локально)
manage.py               команды Django
requirements.txt        зависимости Python
.env.example            шаблон локальных переменных окружения
```

## Основные страницы

- `/` — каталог, поиск и страницы результатов.
- `/event/<slug>/` — подробная информация о событии.
- `/event/new/` — создание события после входа.
- `/accounts/login/` и `/accounts/register/` — вход и регистрация.
- `/admin/` — административная панель Django.

## Перед публикацией

`runserver` и встроенная раздача медиа предназначены для разработки. Для production отключите `DEBUG`, задайте безопасный `SECRET_KEY` и `ALLOWED_HOSTS`, настройте HTTPS, базу данных и отдельное хранилище статических и медиафайлов.
